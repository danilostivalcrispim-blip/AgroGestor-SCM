Bem-vindo ao AgroGestor

Sistema de gerenciamento de propriedades rurais.

Funcionalidades do sistema

  • Cadastro de propriedades rurais
  • Cadastro de produtores
  • Controle da produção agrícola
  • Registro de despesas da propriedade
  • Acompanhamento das atividades rurais

Projeto acadêmico desenvolvido para a disciplina de Projeto de Software.
